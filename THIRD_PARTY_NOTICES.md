# Third-party components

`vendor/cookie-consent` contains the existing compiled distribution of `@premAI-io/cookie-consent` version 1.0.0, copied unchanged from the original website's installed dependency. Its package manifest declares the MIT license. It wraps `vanilla-cookieconsent`, installed separately through the lockfile. The upstream package metadata and README are retained in that directory.

Other dependencies retain their individual licenses in their packages. Fluso/Prem trademarks, artwork and website content retain their existing ownership; making this repository public does not assign a new license to them.
