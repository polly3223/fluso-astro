# Fluso Project References

These files are local working references for design, landing pages, motion, and copy.

- `landing-page-skill.md`
  - Use for landing page structure, hero audits, CTAs, social proof, nav, footer, and conversion checks.
  - Codex skill installed separately as `unicorn-landing`.

- `motion-and-animation.md`
  - Use for Transitions.dev motion patterns and DotMatrix loader / dot-field guidance.
  - Keep animations purposeful, local, responsive, and accessible.

- `writing-and-copy.md`
  - Use for Fluso website copy, product copy, docs, and design-system prose.
  - Prioritize context, concrete specificity, and fact discipline.

- `../../fluso-visual-identity-system.html`
  - The main visual identity HTML reference created from the supplied brand slides and texture assets.
